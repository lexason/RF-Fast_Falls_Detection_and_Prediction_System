USRP N210 — Active FMCW Radar

The primary high-fidelity sensing node. Transmits a linear chirp waveform (f₀=2.4 GHz or 5.8 GHz, B=200 MHz, T_c=1 ms) and receives reflected returns simultaneously using antenna isolation. Produces 10 range-Doppler maps per second. RF isolation from ESP32 nodes: operate USRP on 5.8 GHz band or upper 2.4 GHz channel (ch.11) to avoid CSI corruption on the ESP32 nodes. Coverage: main living room (6–8 m range). Cannot penetrate multiple walls reliably — this limitation is solved by the ESP32 multi-room layer.

ESP32S3 Passive WiFi CSI Nodes (Chen et al. 2024)

Three nodes deployed in bedroom, bathroom, and kitchen — rooms the USRP cannot reliably cover. Each ESP32S3 sends Ping packets to the home router at 100 Hz and receives CSI embedded in the Ping reply. Cost: ~$10 AUD per node including external antenna. Data: 52 OFDM subcarrier amplitudes per packet. Phase is discarded (single-antenna phase noise, per Chen et al.). Receives from existing home WiFi router — no new transmitter hardware required. Key limitation: models trained per-room require separate personalisation due to environment-specific multipath.

IoT Wearable + Environmental Sensors

Wrist-worn IMU (100 Hz, 3-axis accelerometry + gyroscope) provides ground-truth cadence for cross-modal validation and jerk RMS for near-fall detection. Heart rate variability (RMSSD) serves as a fatigue proxy for next-day risk elevation. Environmental sensors (PIR × 4 rooms, door contacts, bedside/bathroom pressure mat) provide room-level context without identifiable video. All BLE to edge hub. The wearable layer is the only modality requiring participant action — kept minimal to preserve compliance.

Edge Hub — Privacy Enforcement Point

The Raspberry Pi 4B is the hard privacy boundary. Raw RF data and raw accelerometry never leave this device. Only feature vectors (compact numerical summaries, not reconstructable into RF signals) are transmitted to the cloud AI layer over TLS. This is a system constraint, not a configuration option. The hub manages NTP synchronisation across all streams (target: ≤50 ms inter-stream error), MQTT ingestion from ESP32 nodes, UHD streaming from USRP, and BLE gateway for wearables.

FMCW Signal Processing Pipeline (GNU Radio)

Raw IQ samples (complex64, 20 MS/s) flow from UHD source → dechirp (multiply with time-delayed TX copy) → low-pass filter → range FFT (N=512, Hann window) per chirp → stack 128 chirps into range-time matrix → Doppler FFT across slow-time → range-Doppler map (128×512). Ten maps/second are produced. A micro-Doppler spectrogram (128 Doppler bins × 300 time bins) is extracted by summing energy across range bins containing a detected human target (CFAR, 12 dB SINR threshold). This spectrogram is the CNN input. Parallel scalar feature extraction runs on the same map stack.

CSI Processing Pipeline (Chen et al. approach, adapted)

Each 3-second window of raw CSI packets (variable ~80–100 received) is resampled to exactly 300 packets via linear interpolation — the standardisation method of Chen et al. Amplitude matrix (300×52) is extracted; phase is discarded. Per-subcarrier z-score normalisation removes static multipath (the DC component of the channel). A 5-tap median filter along the time axis suppresses spike noise. A vertical motion index is computed as the amplitude-weighted sum across subcarriers (weights estimated from calibration data showing which subcarriers are most sensitive to vertical body displacement, per the t-SNE finding of Chen et al.).

FMCW Gait Feature Vector

Extracted per 30-second window (300 range-Doppler maps): cadence (peaks/min in Doppler periodicity); stride symmetry ratio (Doppler energy balance between left/right limb returns); torso-to-limb Doppler energy ratio (proxy for upper body sway); micro-Doppler entropy per frequency band; sway amplitude (lateral Doppler variation during stance phases); step regularity (autocorrelation of stride sequence). These 6 primary features + derived statistics (CV, trend slope) form the 12-element daily summary used by the XGBoost 7-day predictor.

CSI Activity Features (Room-Level)

Produced per 3-second window per active ESP32 node: amplitude variance across the (300×52) matrix (overall motion energy proxy); vertical motion energy ratio using the calibrated subcarrier weight vector; transition event count (high-variance spikes in amplitude — sit-to-stand, stand-to-sit); room occupancy state (thresholded variance, consistent with PIR); subcarrier correlation structure (changes when body position changes vs when it doesn't). The t-SNE finding from Chen et al. motivates the vertical-motion emphasis: CSI at 2.4 GHz most strongly encodes vertical body displacement.

Wearable Feature Vector

16-element vector computed per 30-second window: jerk RMS (sensitive to postural perturbations, key near-fall indicator); step detection-derived cadence (cross-modal validation against FMCW cadence); stride time mean and CV; HRV RMSSD and pNN50 (fatigue proxies for next-day risk elevation); activity bout duration (longest continuous movement bout); sedentary fraction; environmental context flags (time-of-day, room as inferred from PIR, door event in past 60s).

FMCW Micro-Doppler CNN (4-layer)

Input: (B, 1, 128, 300) micro-Doppler spectrogram. Four conv blocks (32→64→128→64 channels) with max-pooling and batch normalisation, followed by adaptive average pooling to (4×4). Output: 64-dimensional gait embedding + activity logits. The embedding encodes gait quality in a compact form suitable for the personalised autoencoder and fusion module. Architecture is intentionally shallow given dataset size constraints (20–50 participants in Phase 1–3) — a ResNet18 backbone would overfit without extensive augmentation.

Modified ResNet18 CSI Classifier (Chen et al. architecture)

Adopts the Chen et al. approach exactly: first conv layer modified to accept single-channel (300×52) input, pretrained ImageNet weights averaged across RGB channels for initialisation, classification head adapted for stroke-specific label set. Three-stage fine-tuning: (1) domain pre-adaptation on Chen et al. + public CSI datasets with backbone layers 1–3 frozen; (2) population fine-tuning on Phase 2 older adult data with layers 1–2 frozen; (3) participant personalisation on first 2 weeks of home monitoring data with only classification heads trained. Falls cluster near sit-to-stand/stand-to-sit in feature space (per Chen et al. t-SNE) — a direct clinical match to the highest-risk activities for stroke survivors.

Multimodal Fusion Module (Cross-Modal Attention)

The FMCW gait embedding (64-d) serves as the query; the room CSI embeddings (R×64) serve as keys and values in a multi-head attention (4 heads). Attended CSI representation (64-d) is concatenated with the FMCW embedding, wearable features (16-d), and environmental context (8-d), totalling 152-d. A learned modality gating MLP (softmax over 4 modality weights) adaptively downweights modalities with poor data quality (e.g., a room node with no occupancy). Final projection to 128-d fused representation feeds all three downstream classifiers. Key design choice: if a room node is unoccupied, its embedding is zeroed and the gating weight collapses to 0 — the fusion is robust to partial sensor coverage.

Fall / Near-Fall Detector (Priority 1)

Binary MLP head (128→64→1, sigmoid) on the fused representation, operating on 3-second windows with 0.5-second slide. Alert threshold: p_fall > 0.85 (tuned for specificity ≥0.90 to prevent alert fatigue). Near-falls (large Doppler transients not followed by low-acceleration sustained state) are included in the positive class. On trigger: immediate clinician dashboard alert; SHA-256 hash of (timestamp, participant_id, risk_score, top SHAP features) written to Hyperledger Fabric ledger. This is the most time-critical inference path — target latency <500 ms from event to alert.

Exercise Adherence Classifier (Priority 2)

Replaces the self-report Exercise Adherence Rating Scale (EARS) with objective RF-derived measurement. Multi-class MLP on 10-second windows, trained to recognise the micro-Doppler and CSI signatures of LiFE exercises: tandem walking, lateral stepping, heel raises, sit-to-stand repetitions, wall push-ups. Output: hourly exercise log aggregated to a daily adherence score (0–24, matching EARS scale for direct comparability with FAST trial data). The t-SNE insight from Chen et al. directly motivates this: sit-to-stand repetitions have a distinctive vertical-motion CSI signature separable from normal transitions.

Gait Quality Monitor + 7-Day Mobility Predictor (Priority 3/4)

Autoencoder (Priority 3): Trained on participant's first 2 weeks of FMCW gait features (their personal "normal"). Reconstruction error on new 30-second windows is z-scored against the calibration distribution. z > 2.0 sustained for ≥3 consecutive windows → elevated risk flag. This is the longitudinal monitoring signal that FAST could not capture — detecting gradual decline before a fall occurs. XGBoost (Priority 4): 12 daily summary features → P(walking speed decline >0.1 m/s in next 7 days). Trained on Phase 3 longitudinal data aligned with clinician assessments. SHAP values decompose every prediction for clinician transparency.

Hyperledger Fabric — Audit Layer

A permissioned local blockchain node on the Dell T2 host. Only alert hashes and clinician response hashes are written — not raw data or feature vectors. Value proposition: tamper-evident record of what the AI predicted and what the clinician did in response. Required for regulatory accountability under EU AI Act (high-risk AI classification) and TGA/FDA oversight. Not used for: raw data storage, federated learning coordination, or access control (standard healthcare IAM handles these). The ledger is append-only; older entries cannot be modified even by the system administrator.

Clinician Dashboard

Surfaces per participant: daily risk score with 7-day sparkline trend; gait quality summary (cadence, symmetry, sway — FMCW-derived, with comparison to participant's own baseline from week 1); exercise adherence heatmap (calendar view, CSI+FMCW combined); room-level activity map showing last 24h occupancy patterns by room (ESP32S3-derived); SHAP feature attribution bar chart for each alert; one-click FAST booster session scheduling integrated with the clinician's calendar. Alert fatigue design: specificity threshold set at ≥0.90, priority tiering ensures fall alerts are visually distinct from gait trend alerts, maximum 2 non-emergency alerts per participant per day.
